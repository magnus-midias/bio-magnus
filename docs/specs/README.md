# Specs

Especificacoes por feature, seguindo o SDD. Uma subpasta numerada por feature (criada conforme surgem, nao no scaffold inicial):

```
001-nome-da-feature/
  spec.md     -> o que (User Stories, requisitos, criterios de sucesso)
  plan.md     -> como (arquitetura, estrutura de pastas, modelo de dados)
  tasks.md    -> tarefas executaveis em ordem, com checkpoints
  contracts/  -> contratos de API e payloads (quando aplicavel)
```

Templates prontos pra copiar (spec, plan, tasks): `~/Documents/cofre-principal/08-programacao-e-desenvolvimento/templates-sdd/`.
